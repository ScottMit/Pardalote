1 spins at each speed (no ramp) and measures the real rate from position reads. 2 runs accelerate–cruise–decelerate moves between 0 and distance and compares each leg's time with the ideal profile — the same test as the bare AccelStepper sketch (25,600 steps at 20,000 / 15,000 took 2,596 ms there). 3 plays a one-segment linear gesture of distance in duration and reports whether it arrived. 4 repeats 1–3 plus one deliberately impossible gesture (which should give up) for minutes, with a PWM servo sweeping on servo pin (−1 = none). Only problems are added to the table; the line below keeps the tally. It rides out disconnects and counts them. Browser times include a little network latency; the Serial Monitor shows the board's own timings.
