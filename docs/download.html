Setup

Three steps to blinking

Install the Arduino library

Install Pardalote from the Libraries tab in the Arduino IDE or copy the Pardalote folder into your Arduino libraries folder and restart the IDE. It appears under File → Examples → Pardalote. Full details in Installation.

Upload an example and join your WiFi

Open minimal-pardalote, upload it to your board, and use the Arduino Serial Monitor to give the board your WiFi details — Pardalote will prompt you on reset and remembers the WiFi between sessions. The board then shows you its IP address via the Serial Monitor. See WiFi configuration for all the options. Prefer to use a USB cable? See connectSerial() — no WiFi details needed.

Open a web page

Put the board's IP address into an example sketch.js and open index.html in your browser. That's it - done.

What you need

Boards and requirements

Pardalote runs on the Arduino UNO R4 WiFi, ESP32 development boards, and the UNO R4 Minima (USB serial only). You'll need the Arduino IDE, a web browser, and a code or plain text editor. Over WiFi, the Arduino and your browser just have to share the same network; with no network, the same code runs over USB in Chrome or Edge.

Some extensions rely on standard Arduino libraries (servo, stepper, NeoPixel support and so on) — the installation guide lists exactly what to install for the hardware you're using.
